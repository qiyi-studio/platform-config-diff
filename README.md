# 📱 平台差異快查

> 查一個功能在六個站點各是怎麼設定的，或查一個站點的所有設定。**值相同的站點會自動併成一組**，一眼看出差在哪。

單一 HTML 檔，用瀏覽器打開就能用。**不需要安裝、不用連伺服器、手機電腦都能開。**

> 📌 這個公開版內建的是**示範資料**（虛構的網購平台設定）。
> 程式邏輯、併組演算法、介面都是完整的，換成自己的資料即可正式使用。

---

## 為什麼做這個

「這個功能在 A 站跟 B 站一不一樣？」——原本要開一份近百列 × 六欄的對照表，
把六格的字**一格一格看過去**，自己判斷哪幾家一樣、哪幾家不一樣。

實際上大多數功能是六家完全相同的，真正有差異的只是一部分。
也就是說一半以上的時間，是在確認「都一樣」這件事。

這個工具直接幫你併好：

- 六家都一樣 → 顯示成**一行**，寫著「全平台相同」
- 有差異 → 值相同的站點自動併成一組，例如「MA／MB／MC：⭕」「MD／ME／MF：❌」

還有一個「**只看有差異的**」按鈕，一按就把相同的全部收起來。

---

## 功能

| 功能 | 說明 |
|---|---|
| 自動併組 | 值相同的站點併成一組，不用自己比對六格 |
| 只看有差異的 | 一鍵過濾掉六家都相同的項目 |
| 依分類瀏覽 | 分成 9 大類（基本設定、安全、分銷、訂單、行動支付、電子錢包、自動化、第三方串接、其它） |
| 兩種查法 | 查一個功能各站點差在哪，或查一個站點的所有設定 |
| 繁簡都查得到 | 打繁體找得到簡體原表 |
| 匯出回試算表 | 整理成 Tab 分隔文字，一鍵複製後貼回試算表 |
| 自己更新資料 | 原表有變動時，把表格 `Ctrl+C` 直接貼進來就好，**不用改程式** |
| 一打開不列結果 | 預設是待命畫面，開始打字或點篩選才顯示，避免誤看到別筆 |

> 這支**刻意沒有「複製給客戶」功能** —— 站點設定是內部資訊，不是拿來給客戶看的。

## 示範資料內容

## 怎麼用

1. 點右上角綠色 **Code** → **Download ZIP**，解壓縮
2. 用瀏覽器打開 `index.html`
3. 打功能名稱，或點分類瀏覽；想快速掃差異就按「只看有差異的」

工具裡有「❓ 使用說明」，寫得比這裡更細。

## 資料與隱私

- 整個工具就是**一個 HTML 檔**，開啟後所有運算都在你自己的瀏覽器裡完成。
- **不會把任何資料送到伺服器**，沒有帳號、沒有登入、沒有追蹤。
- 你貼上的資料只寫在這台裝置的瀏覽器 localStorage，換一台裝置要重貼。

## 技術

| 項目 | 內容 |
|---|---|
| 前端 | 單一 HTML 檔、原生 JavaScript，**無框架、無 npm 依賴、無建置流程** |
| 併組 | 建置時把重複的值抽成共用字串表，六個站點各自指到值的編號，相同編號即自動併組 |
| 搜尋 | 繁簡折疊 ＋ 去符號正規化 |
| 資料匯入 | 優先解析剪貼簿的 `text/html`（才吃得到合併儲存格），純文字為備援 |
| 資料儲存 | 瀏覽器 localStorage（不落地到任何伺服器） |
| 建置 | 資料 JSON ＋ 三段原始碼 → 組成單一 `index.html` |

### 為什麼用「字串表 ＋ 編號」而不是直接存六個字串

同一句設定說明常常六個站點一模一樣，直接存就是同一段文字重複六次。
改成建置時抽出唯一值、每個站點只存一個索引之後：**判斷「這幾家是否相同」退化成比較整數**，
不必做字串比對；而且檔案也小了一截。併組這件事等於是資料結構順便解決的，不是另外寫一套邏輯。

## 檔案結構

```
platform-config-diff/
├── index.html              ← 成品（要用的就是這一個）
└── 原始碼與驗證/
    ├── r1.html             ← 版面與樣式
    ├── r2.js               ← 資料處理、併組、搜尋、繁簡折疊
    ├── r3.js               ← 畫面渲染與互動
    ├── rassemble.js        ← 三段原始碼 ＋ 資料 → index.html
    ├── pairs.txt           ← 繁簡對照表
    └── demo-data.json      ← 示範資料
```

## 重建

需要 Node.js（在 `原始碼與驗證` 資料夾裡執行）：

```bash
node rassemble.js
```

一般使用者**不需要做這一段**，日常資料更新用工具裡的「📋 貼上／更新資料」就好。
